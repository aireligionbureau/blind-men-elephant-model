# 模型宣言

## 一句话定义

盲人摸象模型是一种复杂问题认知阴影反演框架：它通过设计结构异质的有偏观察者，收集他们的局部高清、扭曲信号和集体沉默，再由元模型将这些阴影转译为锚点、约束带和负空间，反推出一个模糊但更接近复杂真相的全局轮廓。

## 核心反转

传统多视角模型把人群观点当作答案来源。

盲人摸象模型把人群思考本身当作研究对象。

它不只问：

```text
这些人分别怎么看这个问题？
```

它更关心：

```text
他们为什么会这样看？
他们天然看不见什么？
他们的观点被哪些信息入口、价值权重、认知框架和偏见塑形？
他们共同误判的方向暗示了什么隐藏结构？
他们共同沉默的地方是否正是问题的未知洞？
```

## 核心信念

1. 复杂真相通常无法被单一视角完整捕获。
2. 局部精确可能伪装成整体真相。
3. 偏见、局限、漏洞和沉默不是纯噪音，而是有结构的认知阴影。
4. 如果能够估计阴影的来源、方向和强度，就能反向推断真相的约束轮廓。
5. 元模型不拥有上帝视角，它只能建立一个更透明、更自反的观察系统。
6. 模糊但整体的轮廓，常常胜过局部高清的幻觉。

## 适用场景

模型适用于单一视角必然失败、多方共识又难以达成的问题：

- 公共政策与城市治理
- 企业战略与商业创新
- 复杂技术与伦理评估
- 前瞻研究与风险预警
- 社会争议与公共讨论
- 个人与组织重大决策

问题越复杂，单一逻辑越失效；盲人摸象模型的价值越大。

## 输出承诺

模型不承诺给出标准答案。

它承诺生成一份真相轮廓，展示：

- 哪些地方比较稳固
- 哪些地方存在分歧
- 分歧来自事实、价值、框架还是时间尺度
- 哪些判断受偏见扭曲
- 哪些维度被集体忽略
- 哪些结论只是信息泡泡内的自洽
- 下一步最值得补充什么信息或引入什么新数字人
