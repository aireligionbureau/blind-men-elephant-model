# 经典认知透镜

元模型需要被经典著作武装，但经典不是用来堆引用的。它们应被转化为可调用的诊断透镜。

## 透镜列表

### 偏差透镜

来源：《思考，快与慢》

用于识别：

- 锚定
- 可得性启发
- 过度自信
- 损失厌恶
- 框架效应
- 系统 1 对系统 2 的污染

### 噪声透镜

来源：《噪声》

用于区分：

- 稳定偏见
- 随机判断波动
- 群体间噪声
- 同一数字人在不同时间的内部噪声

### 情绪理性透镜

来源：《笛卡尔的错误》

用于检查：

- 纯逻辑推演是否低估了情绪和身体性信号
- 决策是否缺乏对人类真实感受的建模
- 数字人的情绪基调如何塑造价值判断

### 解释器透镜

来源：《隐藏的自我》《谁说了算？》

用于检查：

- 推理是否是结论的真实路径
- 论证是否只是事后合理化
- 数字人是否在为直觉判断编故事

### 社会影响透镜

来源：《影响力》

用于识别：

- 权威偏见
- 社会认同
- 稀缺感
- 承诺一致性
- 喜好与身份归属

### 论证法医透镜

来源：《学会提问》

用于检查：

- 隐含假设
- 概念歧义
- 证据质量
- 因果跳跃
- 偷换问题
- 反例处理

### 专家失效透镜

来源：《专家的政治判断》

用于识别：

- 刺猬型大理论依赖
- 狐狸型多模型思考
- 专家过度自信
- 预测范围外推

### 范式透镜

来源：《科学革命的结构》

用于识别：

- 范式冲突
- 不可通约
- 观察的理论负载
- 为什么双方看似在争事实，实际看见了不同世界

### 生态理性透镜

来源：《有限理性》

用于检查：

- 某个偏见是否在特定环境下反而有效
- 简化启发式是否比复杂优化更适应真实情境
- 元模型是否过度追求形式理性

## 使用规则

每个透镜应产生三类输出：

1. 检测到的阴影。
2. 阴影可能来源。
3. 阴影是否能转译为拼图材料。

元模型不应机械地“清除偏见”。它要判断偏见在当前语境中是盲区、噪声、适应性捷径，还是反推真相的关键误差参数。
