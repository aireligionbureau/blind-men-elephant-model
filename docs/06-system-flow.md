# 系统流程

## 运行阶段

### 0. 用户输入复杂问题

用户输入一个开放式复杂问题。

系统不立即回答，而是先判断：

- 问题类型
- 涉及的利益方
- 可能的时间尺度
- 需要覆盖的必要认知维度
- 哪些数字人类型可能有价值

### 1. 生成数字人群

根据问题类型，系统从九维参数空间中生成结构异质的数字人群。

目标不是数量最大，而是认知覆盖最大。

### 2. 过滤式检索

每个数字人基于自身信息摄入身份证生成搜索策略：

- 关键词
- 搜索范围
- 来源偏好
- 排斥来源
- 证据类型偏好

它们不是自由上网，而是像真实人类一样带着过滤器进入信息世界。

### 3. 个体分析

每个数字人按自己的认知身份证分析问题，输出：

- 证据账本
- 核心假设
- 推理路径
- 结论
- 自评置信度
- 结论翻转条件

### 4. 元模型诊断

元模型审计每个数字人的完整链条：

```text
信息过滤 -> 证据选择 -> 假设形成 -> 推理路径 -> 价值评估 -> 结论输出
```

### 5. 阴影显影

元模型标注每个判断中的：

- 信息阴影
- 框架阴影
- 价值阴影
- 推理阴影
- 沉默阴影

### 6. 阴影拼图

将阴影转译为：

- 互锁锚点
- 偏矫正碎片
- 负空间洞

### 7. 真相轮廓报告

输出：

- 候选真相轮廓
- 稳定锚点
- 约束区间
- 分歧结构
- 集体盲区
- 需要补充的证据
- 需要引入的新数字人
- 元模型自反声明

## 后续循环

如果报告发现重大集体盲区，系统应生成“反叛者数字人”或“外卡数字人”重新进入流程。

这使盲人摸象模型成为迭代式认知显影系统，而不是一次性报告生成器。
