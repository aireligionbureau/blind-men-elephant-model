# 运行档位与成本心智

## 推荐档位

### Standard: 24 个数字人

适合大多数复杂问题的一次真相轮廓生成。

目标不是让 24 个人给 24 份意见，而是让 24 个结构不同的信息过滤器和认知身份证暴露足够多的阴影方向。

适用：

- 企业战略
- 产品方向
- 普通公共议题
- 组织重大决策
- 技术伦理初筛

### Deep: 50 个数字人

适合高风险、高外部性、强争议、长周期的问题。

适用：

- 公共政策
- 城市治理
- 高风险技术部署
- 社会争议
- 风险预警
- 需要形成更高覆盖度真相轮廓的研究任务

## 为什么不是越多越好

盲人摸象模型追求的是阴影覆盖率，而不是观点数量。

如果新增数字人不再产生新的：

- 信息阴影
- 价值阴影
- 框架阴影
- 推理阴影
- 沉默阴影
- 约束区间
- 负空间洞

那么继续增加人数只会增加成本和噪声。

## 成本心智

以 deepseek-v4-pro 为主模型时，标准 24 数字人的纯大模型成本通常可按以下心智估计：

- 常见区间：约 3-8 元人民币 / 复杂问题
- 工程保守预算：约 10 元人民币 / 复杂问题

深度 50 数字人：

- 常见区间：约 15-30 元人民币 / 复杂问题
- 如果资料很长、多轮重跑、输出很长，可能更高

不包含：

- 搜索 API
- 网页抓取
- 文档解析
- 向量库
- 重试和失败重跑

## 成本控制原则

1. 固定系统提示、经典透镜和 schema 应尽量利用 provider cache。
2. 数字人不要自由上网，应按信息过滤器检索 3-5 个高相关来源。
3. 元模型不要读取全部原始网页，应读取证据账本、关键摘录和来源索引。
4. 先跑 Standard，再根据集体盲区追加反叛者数字人。
5. 当阴影增量下降时停止扩展。
