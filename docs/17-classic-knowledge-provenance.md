# 经典知识流水线契约

经典知识库不是书名引用库，不是关于用户问题的事实来源，更不是侦探层的上级裁判。它在法医层提供诊断底座，在侦探层提供可拒绝的发现与复核工具：说明阴影为何形成、可能怎样参与拼图，以及这种解释必须停在哪里。侦探的原生材料审查和关系裁决始终独立存在。

## 一条可检查的依据链

每次运行把经典底层转成五类运行时对象：

1. `classic_diagnostic_trace`：记录经典著作、诊断透镜、微透镜、阴影机制和数字人思考链中的具体证据。
2. `inversion_certificate`：规定这条诊断可以怎样参与拼图，授权分为 `provisional`、`restricted` 和 `blocked`。
3. `diagnostic_bridge`：把单人语义判读连接到诊断轨迹与反演许可证，回答“为何这样诊断”和“能推出到哪里”。
4. `classic_connection_hypothesis`：把经典机制转成可证伪的跨人连接搜索问题，只负责提示侦探检查什么。
5. `classic_relation_review`：在材料裁决冻结后，独立判断某件经典工具是否准确解释该关系；它只能写入诊断溯源。

这三个对象必须沿着以下链条保留真实 ID：

```text
经典工具
  -> 单人完整思考链中的具体证据
  -> 语义诊断与阴影材料
  -> 跨人关系证书
  -> 轮廓约束
  -> 最终轮廓陈述
```

最终报告中的陈述可以追溯到关系、拼图和经典诊断工具，但经典只能解释材料的使用方式，不能替代市场数据、搜索结果或其他世界证据。

## 各层职责

### 法医层

- 用经典透镜寻找具体思考链证据，不凭书名贴标签。
- 同时运行差分诊断，防止把相似表象误归为同一机制。
- 把“这个人错了”改写成可核查的链条缺口、适用边界或遗漏条件。

### 侦探层

- 每块诊断材料必须携带轨迹、许可证和桥接依据。
- 侦探先按原生规则固定材料样本和候选容量；经典材料只能限额追加，不得替换原生材料或挤占原生候选。
- 关系裁决调用必须物理移除经典假设、发现路线和经典优先级，只依据材料、坐标、来源谱系、竞争解释与证伪条件。
- 裁决冻结后，经典可以复核“这件工具是否准确解释了关系”，但不得修改关系状态、解释、置信度、证伪条件或真相权重。
- 反演许可证只约束“经典诊断本身允许推出什么”，不能否决由现实材料独立证明的关系。
- 相同经典透镜不构成独立支持；经典来源相同也不能制造内容冲突。
- 未完成差分诊断时，反演只能保持 `restricted` 或 `blocked`。

### 轮廓层

- 约束继承其来源关系的经典依据链。
- 最终陈述继承它所引用的拼图、关系和约束的依据链。
- `blocked` 只能进入未知，`restricted` 只能形成边界或条件。
- 经典不得单独支撑“会”“不会”、概率、时间点或任何方向性事实结论。

## 四条不可破坏的边界

1. `classic_as_world_evidence` 永远为 `false`。
2. 诊断依据不能冒充搜索证据，搜索证据也不能反向伪造诊断依据。
3. 经典可以提出连接候选并增加诊断解释，但不能改变材料事实值，也不能改变已经冻结的材料裁决。
4. 每层都允许“不连接、不反演、不下方向性结论”；完整的追溯链不等于结论已经成立。
5. `classic_truth_weight_bonus` 永远为 `false`；经典复核通过只表示解释工具适配，不表示关系更真实。

## 验收标准

- 所有语义诊断型拼图都能追溯到至少一条经典诊断轨迹。
- 所有采纳关系都可追溯到输入拼图，并明确经典依据是被实际使用、仅继承谱系，还是不适用。
- 所有轮廓约束和最终陈述都能反查来源关系与拼图。
- 任一层出现 `classic_as_world_evidence=true`，整件产物校验失败。
- 经典辅助前后的原生材料集合必须保持不减；经典复核前后的关系状态与所有非溯源字段必须逐项一致。
- `restricted` 或 `blocked` 的诊断不得制造独立会合、因果方向或方向性答案。
- 经典依据不足时，只拒绝或保留该经典解释；关系继续服从独立材料裁决。
