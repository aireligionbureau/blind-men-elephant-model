# 上架前证据与一次成图契约

这轮升级不增加模型调用，不增加串行阶段，不启动自动补盲第二轮，也不改变标准版 24 人和深度版 50 人。

## 一次成图

问题先被本地识别为事实、因果、预测、规范、概念、战略中的一种或多种。每种类型只补充相应的证明义务。数字人群在首次生成时共同覆盖证据、定义、时间、反证和受影响者位置；运行结束后仍缺失的部分进入 `important_unknowns`，不再通过追加人物返工。

缺席席位或损坏文件的定点补齐属于运行恢复，不属于第二轮认知补盲。它只能恢复原定人数和原定任务，不能根据首轮结论追加新立场。

## 句子级证据资格

用户仍看到自然中文段落。后台只对 `direct_answer` 和 `main_contour` 的完整句子分别记录：

- 这句话具体说了什么。
- 它承担事实、方向、条件、结构、定义、未知或价值中的哪一种责任。
- 它引用了哪些拼图、关系与约束。
- 这些材料是否有资格承担这种责任。

已核验事实必须引用页面、原始来源或交叉核验材料。方向判断必须引用来源与发布者均独立、且被授权支持方向的会合关系。没有这些资格时，轮廓仍可说明结构、条件和未知，但不能把搜索摘要或群体相似意见写成现实事实。

## 来源血缘

系统在已有检索结果上本地计算三层血缘，不发起额外网络请求：

1. 规范化网址是否相同。
2. 发布者是否相同。
3. 标题或摘要是否显示为同一原始稿件。

两家媒体转载同一稿件不算两份独立证据。模型先验始终标记为共享底座，只能显影数字人搜索前的预设。

## 经典知识边界

经典知识帮助发现思维阴影、提出竞争解释、限定关系用法和反演边界。它不能证明外部世界事实，不能修改侦探已经冻结的关系裁决，也不能单独赋予方向性权重。

## 性能不变量

- 新问题语法是纯本地规则。
- 认知覆盖评分是纯本地集合计算。
- 来源血缘是纯本地归一化与哈希。
- 逐句证据审查发生在既有最终轮廓调用及本地校验中。
- 数字人群请求和带过滤器检索请求使用信息等价的紧凑 JSON；24 人运行中节省发生在每人的既有调用里，用来抵消最终轮廓新增证据标签的 token 开销。
- 正常文件写入不等待；只有 Windows 瞬时文件占用时才执行短暂有限重试。

## 供应商边界

DeepSeek 是默认配置，不是流水线结构。模型接入使用 OpenAI Chat Completions 兼容契约；数字人群生成及定点补齐复用同一个可注入客户端，法医、侦探和轮廓既有调用也沿用该契约。供应商不支持的 `thinking` 字段会在客户端边界被省略，不会要求业务层分叉，也不会增加适配调用。

## 本地无损验收

以标准版 24 人夹具测量，检索规划 JSON 从 28,074 字符降到 18,582 字符，减少 9,492 字符（33.81%）；人群生成 JSON 从 1,207 字符降到 820 字符。问题语法 10,000 次本地执行的单次平均耗时约 0.006 毫秒。冻结运行的离线审计记录外部调用为 0，侦探材料包可逆、轮廓材料包可逆、反方压力包合计无损三项门槛均通过。该验收不发出外部请求；真实供应商的端到端耗时仍应以正式无缓存运行记录为准。
